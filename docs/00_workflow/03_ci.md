# 03. CI trên nhánh experiment

> Đọc file này khi: CI báo đỏ, hoặc muốn biết CI kiểm những gì.
> Liên quan: `docs/06_plan/P6_reports_ci.md`, `docs/00_workflow/05_git_commits.md`

## Khi nào chạy

- Khi push lên nhánh `experiment`.
- Khi mở pull request vào nhánh `experiment`.

## Kiểm tra 6 chỗ

| #   | Kiểm gì                                                                                     | Chặn lỗi gì                           |
| --- | ------------------------------------------------------------------------------------------- | ------------------------------------- |
| 1   | Không có file **dữ liệu** bị git theo dõi, ngoài bảng chi tiết trong `pipeline/`, `eda/`   | vô tình commit dữ liệu                |
| 2   | `.gitignore` đúng: file dữ liệu bị bỏ qua, file metadata và report thì không                | mất metadata hoặc commit nhầm dữ liệu |
| 3   | Notebook đã được làm sạch output                                                            | diff GitHub đầy rác                   |
| 4   | Mọi registry đều hợp lệ (gọi `check()` cho từng trục)                                       | thêm module nhưng quên đăng ký        |
| 5   | Mọi `experiments/**/config.yaml` hợp lệ: hợp nhất được, có `roles`, dataset version tồn tại | lỗi config phát hiện muộn trên Colab  |
| 6   | `REPO_SHA` trong notebook là sha hợp lệ và tồn tại trong repo                               | ghim sai hoặc sha không tồn tại       |

Check 1 không được phép cấm mọi file trong `data/`: theo luật 20, metadata và report **phải**
được git theo dõi. Danh sách được phép có trong `data/`:

| Nhóm                                             | Vì sao được theo dõi                        |
| ------------------------------------------------ | ------------------------------------------- |
| `raw_meta.yaml`                                  | nguồn, số dòng, sha256 của một phiên bản raw |
| `processing_log.json`, `label_map.json`           | dấu vết tạo ra dataset                      |
| `pipeline/**`, `eda/**`                           | báo cáo và bảng chi tiết của từng lần chạy   |
| `data/reports/**`                                 | bảng tổng hợp bốn nhóm (xem P6 T1) - thứ người đọc mở ra xem, còn mục lục `experiment_registry/runs/` thì bị bỏ qua |
| `data/assets/`, `data/reference_publication/`     | tài nguyên dùng chung và số liệu công bố     |
| `.gitkeep`                                        | giữ thư mục rỗng trong git                  |

Sau đó chạy `pytest -q tests/`.

## CI không làm gì

- Không chạy model, không cần GPU.
- Không đọc `data/`, vì dữ liệu không nằm trong repo. Lỗi phụ thuộc dữ liệu do preflight trong notebook bắt.
- Không gọi Drive, không gọi DagsHub.
- Không chạy notebook thật.

## Khi CI đỏ

1. Mở log của bước bị đỏ, đọc dòng lỗi cuối cùng.
2. Sửa đúng chỗ, chạy lại `python scripts/ci_checks.py` và `pytest -q tests/` ở máy.
3. Commit bổ sung, không amend commit cũ.
