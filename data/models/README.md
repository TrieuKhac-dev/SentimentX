# data/models

Đặt model tải về ở đây, mỗi model một thư mục con tên bằng `model_id`.
Ví dụ: `qwen3-4b-instruct-2507/`, `qwen3-0.6b/`, `vncorenlp/`.

Nội dung thư mục này KHÔNG được commit: `.gitignore` bỏ qua `data/models/*`.
Tải lại bằng script cài đặt tương ứng trong `scripts/`, không copy qua lại bằng tay.
